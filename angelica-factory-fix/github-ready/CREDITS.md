## HBM compatibility changes

This repository contains an unofficial community workaround developed for a player's HBM factory rendering problem, with AI-assisted development using OpenAI Codex. Its scope is documented in [hbm-patch/CHANGES.md](hbm-patch/CHANGES.md). It does not transfer ownership of Angelica or imply support or approval from the Angelica, GTNH, or HBM teams.

Base version: **Angelica 2.2.36**.

Base commit: **e84c8c8d7accd6df0c93340c8409d997a43b9aaa**.

Build-only libraries: [ASM](https://asm.ow2.io/) and [fastutil](https://fastutil.di.unimi.it/), downloaded separately. Their original notices are retained by their distributions. Minecraft and HBM binaries are not included in the source upload.
